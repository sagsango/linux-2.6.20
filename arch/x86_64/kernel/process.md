process.c is the x86-64 architecture layer for task management:
it implements idle handling, context switching, fork/clone/vfork,
execve, TLS (FS/GS) management, debug register switching, I/O
permission switching, CPU hotplug idle shutdown, and the low-level
CPU state transitions that make multitasking work on x86-64.
