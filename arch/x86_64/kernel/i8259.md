```text
===============================================================================
x86/x86_64 IRQ SUBSYSTEM BOOTSTRAP
File: arch/x86_64/kernel/i8259.c / irq.c (Linux 2.6 era)
===============================================================================

PURPOSE
=======

This file initializes the entire interrupt subsystem during boot.

It handles:

    - Building IRQ entry stubs
    - Setting up IDT interrupt gates
    - Initializing 8259 PIC
    - APIC interrupt vectors
    - IRQ descriptor setup
    - SMP IPIs
    - PIT timer initialization
    - Legacy ISA interrupts

This is one of the most important interrupt files in early x86 boot.

===============================================================================
BIG PICTURE
===============================================================================

Device Interrupt
       |
       v
8259 PIC or IOAPIC
       |
       v
CPU receives vector
       |
       v
IDT entry
       |
       v
IRQxx_interrupt()
       |
       v
do_IRQ()
       |
       v
generic_handle_irq()
       |
       v
device driver ISR


===============================================================================
BOOT FLOW
===============================================================================

start_kernel()
      |
      v
init_IRQ()
      |
      +--> init_ISA_irqs()
      |
      +--> setup IDT vectors
      |
      +--> setup SMP IPI vectors
      |
      +--> setup APIC vectors
      |
      +--> setup PIT timer
      |
      v
interrupts ready


===============================================================================
PART 1: BUILDING IRQ ENTRY STUBS
===============================================================================

Macros:

    BUILD_IRQ()

    BUILD_16_IRQS()

generate assembly handlers:

    IRQ0_interrupt
    IRQ1_interrupt
    IRQ2_interrupt
    ...
    IRQ255_interrupt


Generated handlers:

IRQxx_interrupt
      |
      +--> save registers
      |
      +--> call do_IRQ()
      |
      +--> restore registers
      |
      +--> iretq


===============================================================================
WHY SO MANY IRQ STUBS?
===============================================================================

Every vector needs its own IDT target.

Example:

Vector 0x20
      |
      v
IRQ0_interrupt

Vector 0x21
      |
      v
IRQ1_interrupt

Vector 0x22
      |
      v
IRQ2_interrupt


Thus Linux generates hundreds of small stubs.


===============================================================================
PART 2: INTERRUPT VECTOR TABLE
===============================================================================

Array:

static void (*interrupt[])(void)

Contains:

    interrupt[0] -> IRQ0_interrupt
    interrupt[1] -> IRQ1_interrupt
    ...
    interrupt[n]


Used later:

    set_intr_gate(vector, interrupt[i])


===============================================================================
PART 3: THE 8259 PIC
===============================================================================

Legacy PC interrupt controller.

Two chips:

    Master PIC
    Slave PIC


Layout:

                Master PIC
              IRQ0 ... IRQ7
                     |
                     |
                  IRQ2
                     |
                     v
                Slave PIC
              IRQ8 ... IRQ15


===============================================================================
8259 PORTS
===============================================================================

Master:

    Command 0x20
    Data    0x21

Slave:

    Command 0xA0
    Data    0xA1


===============================================================================
PIC MASK REGISTER
===============================================================================

Variable:

    cached_irq_mask


Tracks which IRQs are disabled.

Example:

    bit = 1 => masked
    bit = 0 => enabled


===============================================================================
disable_8259A_irq()
===============================================================================

Purpose:

    Mask IRQ line.


Flow:

disable_8259A_irq(irq)
      |
      +--> set mask bit
      |
      +--> write PIC mask register


Example:

IRQ5 disabled

    cached_irq_mask |= (1<<5)

write:

    outb(...,0x21)


===============================================================================
enable_8259A_irq()
===============================================================================

Purpose:

    Unmask IRQ line.


Flow:

enable_8259A_irq(irq)
      |
      +--> clear mask bit
      |
      +--> write PIC register


===============================================================================
PART 4: ACKNOWLEDGING INTERRUPTS
===============================================================================

Most important function:

    mask_and_ack_8259A()


Purpose:

    Tell PIC:

        "Interrupt processed."


Without ACK:

    PIC will not deliver new interrupts.


===============================================================================
INTERRUPT ACK FLOW
===============================================================================

IRQ arrives
      |
      v
CPU executes handler
      |
      v
mask_and_ack_8259A()
      |
      +--> mask interrupt
      |
      +--> send EOI
      |
      v
PIC ready again


===============================================================================
EOI (END OF INTERRUPT)
===============================================================================

PIC requires EOI command.

Master:

    outb(0x60+irq, 0x20)

Slave:

    outb(...,0xA0)

and also:

    outb(0x62,0x20)

to acknowledge cascade IRQ2.


===============================================================================
SPURIOUS IRQ DETECTION
===============================================================================

Common old hardware bug:

    IRQ7
    IRQ15

appear without real interrupt source.

Linux detects:

if (cached_irq_mask & irqmask)

Then verifies:

    i8259A_irq_real()

If fake:

    printk("spurious 8259A interrupt")


Flow:

IRQ7
  |
  +--> real?
          |
          +--> yes -> handle
          |
          +--> no  -> spurious warning


===============================================================================
PART 5: init_8259A()
===============================================================================

Purpose:

    Fully program both PIC chips.


Flow:

init_8259A()
      |
      +--> mask everything
      |
      +--> initialize master PIC
      |
      +--> initialize slave PIC
      |
      +--> configure EOI mode
      |
      +--> restore masks


===============================================================================
MASTER PIC CONFIGURATION
===============================================================================

ICW1:

    outb(0x11)

start initialization


ICW2:

    outb(0x20)

Map IRQ0-7 to vectors:

    0x20 - 0x27


Before remapping:

    IRQ0 conflicted with CPU exceptions.


===============================================================================
SLAVE PIC CONFIGURATION
===============================================================================

ICW2:

    outb(0x28)

Maps:

    IRQ8-15

to:

    0x28 - 0x2F


===============================================================================
FINAL PIC VECTOR MAP
===============================================================================

IRQ0   -> vector 0x20
IRQ1   -> vector 0x21
IRQ2   -> vector 0x22
...
IRQ7   -> vector 0x27

IRQ8   -> vector 0x28
...
IRQ15  -> vector 0x2F


===============================================================================
PART 6: ELCR
===============================================================================

ELCR:

    Edge/Level Control Register

Ports:

    0x4D0
    0x4D1


Controls:

IRQ
 |
 +--> Edge triggered
 |
 +--> Level triggered


Saved during suspend:

    save_ELCR()

Restored during resume:

    restore_ELCR()


===============================================================================
PART 7: IRQ DESCRIPTORS
===============================================================================

init_ISA_irqs()


Initializes:

    irq_desc[]


For every IRQ:

irq_desc[i]
    |
    +--> status
    +--> action
    +--> chip
    +--> handler


===============================================================================
IRQ CHIP LAYER
===============================================================================

IRQ chip:

    i8259A_chip


Provides operations:

    mask()
    unmask()
    ack()


Generic IRQ code calls these through function pointers.


Diagram:

irq_desc
    |
    +--> chip
            |
            +--> mask()
            +--> unmask()
            +--> ack()


===============================================================================
PART 8: VECTOR -> IRQ MAPPING
===============================================================================

Per CPU array:

    vector_irq


Maps:

Vector -> IRQ


Example:

Vector 0x20
      |
      v
IRQ0

Vector 0x21
      |
      v
IRQ1


===============================================================================
PART 9: PIT TIMER
===============================================================================

setup_timer_hardware()


Programs PIT (8254).

Ports:

    0x43
    0x40


Flow:

configure mode
      |
      v
write reload value
      |
      v
timer starts ticking


===============================================================================
PIT PATH
===============================================================================

8254 PIT
      |
      v
IRQ0
      |
      v
Vector 0x20
      |
      v
timer interrupt


===============================================================================
PART 10: init_IRQ()
===============================================================================

Main interrupt initialization routine.


Flow:

init_IRQ()
      |
      +--> init_ISA_irqs()
      |
      +--> install IRQ vector gates
      |
      +--> install SMP IPIs
      |
      +--> install APIC vectors
      |
      +--> initialize PIT
      |
      +--> setup IRQ2 cascade
      |
      v
interrupt subsystem ready


===============================================================================
IDT INSTALLATION
===============================================================================

for each vector:

    set_intr_gate(vector, interrupt[i])


Result:

IDT
 |
 +--> 0x20 -> IRQ0_interrupt
 +--> 0x21 -> IRQ1_interrupt
 +--> 0x22 -> IRQ2_interrupt
 ...
 +--> 0xFF -> IRQ255_interrupt


===============================================================================
SMP INTERRUPT VECTORS
===============================================================================

Installed only when CONFIG_SMP.

RESCHEDULE_VECTOR
----------------------------------------------------------------------------

Handler:

    reschedule_interrupt


Purpose:

    wake CPU and force scheduler run.


CPU0
 |
 +--> send reschedule IPI
 |
 v
CPU1 scheduler runs


----------------------------------------------------------------------------
CALL_FUNCTION_VECTOR
----------------------------------------------------------------------------

Handler:

    call_function_interrupt


Purpose:

    execute function on remote CPU.


Example:

    smp_call_function()


----------------------------------------------------------------------------
INVALIDATE_TLB_VECTOR_START
----------------------------------------------------------------------------

Handlers:

    invalidate_interrupt0..7


Purpose:

    TLB shootdown.


CPU0 updates page table
       |
       v
send invalidate IPI
       |
       v
CPU1 flushes TLB


===============================================================================

===============================================================================

Handler:

    apic_timer_interrupt


Used for:

    scheduler ticks
    profiling
    time accounting


Flow:

Local APIC timer
      |
      v
LOCAL_TIMER_VECTOR
      |
      v
apic_timer_interrupt()


===============================================================================
THERMAL INTERRUPT
===============================================================================

Vector:

    THERMAL_APIC_VECTOR

Flow:

CPU overheating
      |
      v
thermal_interrupt()


===============================================================================
THRESHOLD INTERRUPT
===============================================================================

Vector:

ERROR APIC VECTOR

Vector:

===============================================================================
IRQ2 CASCADE
===============================================================================

Old PCs connect slave PIC through IRQ2.

Thus Linux installs:

    irq2

Action name:

    "cascade"


Flow:

      |
      v
Master IRQ2
      |
      v
cascade handler
      |
      v
real IRQ8-15

===============================================================================
KEY IDEA
===============================================================================

This file is the bridge between:

    Hardware interrupt controllers
            (8259 / APIC / PIT)

and

    Linux generic IRQ subsystem.

It:

    - programs the legacy PIC
    - builds IRQ vector handlers
    - fills the IDT
    - initializes irq_desc[]
    - installs SMP IPIs
    - sets up timer interrupts

After init_IRQ() finishes, Linux is capable of receiving and processing
hardware interrupts from devices across the system. :contentReference[oaicite:0]{index=0}
```
